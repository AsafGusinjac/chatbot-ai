Digitalis chat bot

Lokalni test — baza sa 10.692 proizvoda iz Digitalis kataloga (veleprodaja).

Kliknite narandžasti krug dolje desno i pitajte nešto. Na primjer: „Imate li klima uređaj do 1000 KM?“

Digitalis, ne D-Store

Ovo je test stranica za digitalis.ba (veleprodaja) — koristi digitalis.ba cijene/URL stil i logo. D-Store (dstore.ba, maloprodaja) je poseban sajt sa svojim logom i URL stilom — testira se na demo-dstore.html. Dijele isti katalog, ali su različiti sajtovi.

Kako se stavlja na stranicu

Jedna linija, prije </body> na digitalis.ba:

<script src="https://digitalis.ba/chatbot/public/embed.js"
        data-endpoint="https://digitalis.ba/chatbot/endpoint/chat.php"
        defer></script>

Bez CSS fajla, bez jQuery, bez ičega drugog.

Zašto ne može pokvariti stranicu

Widget se crta unutar Shadow DOM-a — izolovanog dijela stranice. CSS sa stranice ne ulazi unutra, a CSS widgeta ne izlazi napolje.

Ova test stranica ima namjerno agresivno pravilo: button { background: red !important; font-size: 40px !important }. Pogledajte dugme ispod — pocrvenjelo je. Widget je netaknut.

Podešavanja

Sve se mijenja preko atributa na <script> tagu:

  • data-title — naslov u zaglavlju
  • data-greeting — prva poruka
  • data-color — boja (npr. #e11d48)
  • data-position — right ili left
  • data-logo — URL logo slike za avatar

Ko je kupac (ID, ime, da li je veleprodaja) se ne stavlja na <script> tag — stranica to šalje kroz mali JS "queue" obrazac koji radi bez obzira da li se pozove prije ili poslije embed.js:

<script>
  window.DstoreChat = window.DstoreChat || function () {
    (window.DstoreChat.q = window.DstoreChat.q || []).push(arguments);
  };
  DstoreChat('identify', {
    customerId: '12345',
    customerName: 'Ivan Ivić',
    isWholesaleCustomer: true
  });
</script>
